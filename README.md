# Atul Shiv Shakti — Vedic Astrologer

Professional astrology website for **Atul Shiv Shakti**. Built with React, TypeScript, Vite, Tailwind CSS v4, and Motion.

## Live site

**https://lilkunal.github.io/Atulshivshakti/**

## Run locally

```bash
npm install
npm run dev
```

## Features

- Premium cosmic UI with scroll animations (Motion)
- 2 themes: Cosmic Night & Temple Dawn
- Services + WhatsApp booking
- Free Kundli form, Panchang, Rashifal
- Testimonials, FAQ, Blog, Contact
- Fully mobile responsive

## Deploy

Pushes to `main` auto-deploy via GitHub Actions to GitHub Pages.

```bash
npm run build
```
